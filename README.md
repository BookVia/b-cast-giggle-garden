# B Cast — Giggle Garden

Public source repository for the private production dashboard and software pipeline. Separate from the BookVia application.

The dashboard is hosted at https://b-cast.bookvia.org. YouTube connection and analytics UI are implemented, but Google OAuth configuration and channel consent remain outstanding. All CGI candidates remain unapproved; no completed episodes are claimed.

Cloud-hosted Blender use is restricted to bounded pipeline development and testing. GitHub Actions is not treated as an unlimited production render farm. No paid runners are enabled. Bounded standard-runner compatibility tests can be started manually.
